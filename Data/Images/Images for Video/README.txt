HP CHANNEL — ОБЩАЯ БИБЛИОТЕКА ИЗОБРАЖЕНИЙ

Сейчас в каталоге 31 JPG-файл: 1.jpg–31.jpg.
Файлы физически находятся в этой папке. Сайт ссылается на них локально.
Исходные страницы, авторы и условия лицензий записаны в catalog.txt.

ПРАВИЛА ДЛЯ БУДУЩИХ ИЗМЕНЕНИЙ
1. Работать только в новой ветке, созданной от актуальной main.
2. Не обновлять старые ветки, если их изменения уже включены в main.
3. Перед добавлением изображения убедиться, что это фотография по теме статьи.
4. Сохранять реальный файл в этой папке под следующим свободным номером.
5. Проверять открытие JPEG, размер, лицензию и источник.
6. Не использовать один номер фотографии для разных карточек статей.
   Русская и английская версии ОДНОЙ статьи используют один номер.
7. Обновить catalog.txt, карту Data/Assets/article-photo-map.json и локальные ссылки.
8. Выполнить python3 Data/Assets/check_site.py (нужен Pillow).
9. Создать Pull Request, дождаться зелёной проверки, проверить картинки глазами.
10. Только владелец проекта выполняет Merge. Никакого автоматического слияния.

Если PR устарел и его изменения уже присутствуют в main, закрыть его без Merge.
Не разрешать конфликты механически: это может восстановить старые фотографии.
Старые workflow импорта изображений отключены, чтобы не переписывать файлы.
