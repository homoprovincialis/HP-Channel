HP CHANNEL — ИЗОБРАЖЕНИЯ ДЛЯ ВИДЕО

Назначение: общая библиотека фотографий для видеоверсий статей HP Channel.

ПОРЯДОК

1. Нумерация сквозная: 1.jpg, 2.jpg, 3.png и далее, без пропусков
   по возможности. Номер не повторяем даже при разных расширениях.
2. Не переименовывать уже пронумерованные фотографии.
3. Для каждого номера вести запись в catalog.txt:
   что видно, к каким темам подходит, источник, автор, лицензия.
4. Одно изображение может использоваться в разных видео.
5. До публикации проверять лицензию и условия использования оригинала.
6. Сверять описание с фактически загруженным изображением.

СТАТУС

Номера 1–8 зарезервированы в catalog.txt за фотографиями из первоначального
макета HP Channel. Пока сохранены только ссылки на оригиналы и описания.
Сами JPG-файлы ещё НЕ загружены в GitHub.
После загрузки файлов их имена должны совпадать с номерами каталога.
Следующему новому изображению присваивается номер 9.
