HP CHANNEL — ОБЩАЯ БИБЛИОТЕКА ИЗОБРАЖЕНИЙ ДЛЯ ВИДЕО

Папка «data/images for video» предназначена для фотографий,
которые используются на сайте HP Channel и в видеоверсиях статей.

Файлы должны называться последовательными номерами:
1.jpg, 2.jpg, 3.jpg и далее (или с фактическим расширением .png/.webp).

Правила:
1. Номер уникален, независимо от расширения файла.
2. Не загружать повторно изображение, которое уже есть в каталоге.
3. Для каждого номера в catalog.txt указывать описание того,
   что изображено, возможные темы, страницы сайта и источник.
4. Перед публикацией видео проверять автора, лицензию и права.
5. Не менять номер уже используемого изображения.
6. Существующие фотографии сайта имеют закреплённые номера 1–14.
   Но пока они загружаются на сайт по внешним URL — их файлы
   в этом репозитории ещё не сохранены.

Для каждого отдельного выпуска можно создавать свою подпапку
(например, «video 1»), в которой будет список или копии изображений,
использованных именно в этом видео.

Новые изображения добавлять только при подготовке конкретных материалов,
сохраняя единый общий каталог и без выдуманных записей.
