# HP Channel

Философское СМИ Homo Provincialis.

## Структура репозитория

- `index.html`, `en.html` — главные страницы RU/EN.
- `*.html` в корне — страницы разделов RU/EN.
- `Articles/` — отдельные статьи и исследования в формате HTML.
- `Videos/Video 1/` — TXT-сценарий первого видео и список источников кадров. Здесь нет видеофайлов.
- `Data/Assets/` — общие стили и JavaScript.
- `Data/Images/Images for Video/` — общая библиотека изображений и каталог.
- `Data/Documents/Video Scripts/` — инструкции и шаблоны по подготовке видео.

Каждая статья и её видеоверсия используют один и тот же утверждённый текст.

## Порядок изменений и проверок

- Для каждой задачи создавать новую ветку **от актуальной `main`**.
- Создавать Pull Request, не выполнять автоматическое слияние.
- Проверять GitHub Actions **Validate HP Channel website** до Merge.
- Проверка читает файлы, проверяет внутренние ссылки, JPEG и отсутствие повторов фотографий на разных карточках. Она ничего не изменяет.
- При конфликтах сначала проверить, не вошли ли изменения старого PR в `main` через более новый PR. Если вошли — закрыть старый PR без Merge; иначе перенести только нужные изменения в новую ветку от `main`.
- Не запускать старые импортёры фотографий: они рассчитаны на прежний состав файлов и могут переписать каталог.
- Перед добавлением новых материалов обновить карту `Data/Assets/article-photo-map.json`, библиотеку изображений и `catalog.txt`. Одна статья в RU/EN — одна фотография; разные статьи — разные фотографии.
- Запуск локальной проверки: `python -m pip install Pillow`, затем `python Data/Assets/check_site.py`.

**Важно:** автоматические проверки не заменяют просмотр фотографии человеком и проверку условий лицензии.
